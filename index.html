IoT Weather Monitoring System

Built an autonomous real-time micro-weather station using ESP8266 Wi-Fi microcontroller for continuous environmental data acquisition and cloud monitoring.

CORE CONTROLLER ESP8266 NodeMCU Wi-Fi
CLOUD PLATFORM Blynk IoT Dashboard & Mobile App
MONITORED METRICS Temperature • Humidity • Pressure

Connected precision digital temperature, humidity, and barometric pressure sensors to stream live telemetry to a custom Blynk IoT dashboard. Implemented automatic reconnect routines, low-latency sampling loops, and threshold-based notification alerts for environmental anomalies.

ESP8266 Blynk IoT Sensors Interfacing Wi-Fi Telemetry C++ Remote Monitoring
03
CONTROL SYSTEMS / RENEWABLE ENERGY
CLOSED-LOOP AUTOMATION

Dual-Axis Solar Tracking System

Engineered an automated dual-axis solar tracker utilizing a PIC16F877A microcontroller to maximize solar energy harvesting efficiency throughout daylight hours.

CORE CONTROLLER PIC16F877A Microcontroller
OPTICAL SENSING 4-Quadrant LDR Differential Array
ACTUATION Dual Micro Servo Motors (Pan & Tilt)

Designed a closed-loop feedback mechanism where four Light Dependent Resistors (LDRs) detect solar irradiance differentials across azimuth and elevation planes. The PIC microcontroller computes positional error and commands dual servo motors to track the sun's trajectory dynamically, significantly improving power output over fixed panels.

PIC16F877A LDR Sensor Array Servo Motors Closed-Loop Feedback Embedded C Renewable Energy
